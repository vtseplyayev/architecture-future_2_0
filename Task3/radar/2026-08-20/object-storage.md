Основное хранилище аналитических данных с разделением storage и compute.

**Поддерживает:** БС-1 (масштабирование под сотни ТБ), снижение затрат — платим за вычисления только во время запросов.

**Почему adopt:** отраслевой стандарт для Lakehouse, снимает потолок вертикального масштабирования SQL Server (`E3`).
